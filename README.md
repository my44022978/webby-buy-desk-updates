# Webby Buy Desk updates

Public, token-free update channel for the invited Mac friend beta.

- `friend-beta.json` is the only active update feed.
- Release assets are distributable update packages and are publicly downloadable.
- This repository contains no login data, cookies, browser profiles, private keys, or API tokens.
- Only the repository owner has write access. Pull requests or forks do not alter the active feed.
- SHA-256 detects corruption and mismatch with the feed; it is not publisher authentication if this repository account is compromised.
- Apple signing/notarization is deferred until distribution expands beyond the friend beta.

The application source repository and its history remain private. Do not file product-development work in this update-only repository.
